# ScamShield GR — MVP 0.2

## Τι περιλαμβάνει
- Responsive ελληνική ιστοσελίδα.
- Rule-based έλεγχο ύποπτων μηνυμάτων.
- Ενδείξεις για πίεση, πληρωμές, αιτήματα κωδικών, links, συντομευμένα links, IP URLs και ορισμένα μοτίβα domains.
- Παραδείγματα, οδηγίες ασφάλειας και σελίδα πλάνων με σαφή ένδειξη ότι οι πληρωμές δεν είναι ενεργές.
- Η ανάλυση κειμένου γίνεται τοπικά στον browser από το `script.js`.

## Τοπική δοκιμή
Άνοιξε το `index.html` σε browser. Δεν απαιτείται εγκατάσταση ή API key.

## Αναβάθμιση υπάρχοντος GitHub Pages
1. Άνοιξε το repository `scamshield-gr`.
2. Επίλεξε **Add file → Upload files**.
3. Από τον αποσυμπιεσμένο φάκελο v2, ανέβασε τα `index.html`, `styles.css`, `script.js` και `README.md` στο root του repository.
4. Αν το GitHub ρωτήσει για αντικατάσταση αρχείων, επίλεξε τη νέα έκδοση και κάνε **Commit changes**.
5. Το GitHub Pages θα ξαναχτίσει τη σελίδα αυτόματα. Περίμενε λίγα λεπτά και κάνε hard refresh (Ctrl+F5).

## Όρια / ασφάλεια
- Δεν είναι antivirus και δεν κάνει live reputation check σε URLs.
- Η βαθμολογία είναι ευρετική και μπορεί να έχει false positives/false negatives.
- Μην εισάγεις κωδικούς, στοιχεία κάρτας ή άλλα ευαίσθητα δεδομένα.
- Το UI πλάνων είναι μόνο παρουσίαση. Δεν υπάρχει checkout, billing, backend, user account ή πραγματική συνδρομή.
- Μην ισχυριστείς ότι ανιχνεύει όλες τις απάτες. Επιβεβαίωσε σημαντικά αιτήματα από ανεξάρτητο επίσημο κανάλι.
- Πριν από εμπορική λειτουργία, χρειάζονται δοκιμές, προσβασιμότητα, πολιτική απορρήτου/όροι, φορολογικός έλεγχος και σχεδιασμός ασφαλούς backend αν προστεθούν πληρωμές.

## Πλάνο πρώτων χρηστών
1. Κάνε δοκιμή με 10–20 άτομα και ζήτησε feedback.
2. Μέτρα: πόσοι ολοκληρώνουν έλεγχο, πόσοι επιστρέφουν, ποια παραδείγματα χρησιμοποιούν.
3. Δημοσίευσε εκπαιδευτικά short videos με ψεύτικα/ανωνυμοποιημένα παραδείγματα και σαφή εξήγηση των red flags.
4. Μην ενεργοποιήσεις χρεώσεις πριν επιβεβαιώσεις επαναλαμβανόμενη χρήση και προθυμία πληρωμής.
